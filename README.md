## Panduan Menjalankan Kode Secara Lokal:
1. Buka folder ini di **Visual Studio Code** (`File` -> `Open Folder...`).
2. Untuk berkas `index.html`:
   - Klik kanan `index.html` dan pilih **'Open with Live Server'** atau langsung klik dua kali untuk membuka di browser Google Chrome/Edge/Firefox.
3. Untuk berkas `index.php`:
   - Jalankan terminal VS Code atau command prompt di folder ini, lalu ketik:
     ```bash
     php -S localhost:8000
     ```
   - Buka browser pada alamat `http://localhost:8000`.
   - Atau salin berkas ini ke folder `htdocs` XAMPP Anda.
